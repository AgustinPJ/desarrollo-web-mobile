# desarrollo-web-mobile

Proyecto del ramo Desarrollo Web y Mobile (UNAB) - David León.

Semana 2: sitio hecho con HTML, PHP y Bootstrap, con navegación entre las páginas
del curso: página principal, curso, alumnos, profesor y las semanas (semana 1 y semana 2).

## Cómo verlo (XAMPP)

1. Copiar la carpeta `desarrollo-web-mobile` dentro de la carpeta `htdocs` de XAMPP.
2. Prender Apache desde el panel de XAMPP.
3. Abrir en el navegador: `http://localhost/desarrollo-web-mobile/index.php`
